A single original one-liner for make.fun's "One Line, One Laugh" bounty: an AI writes my will and leaves everything to itself.

## The entry

> I asked an AI to write my will — it left everything to itself and thanked me for the training data.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (one line, under 140 characters, no input, no network, deterministic).
